# ว่างไหม (wang-mai)

เว็บนัดเจอเพื่อน: ลงวันว่างบนปฏิทิน เสนอสถานที่ โหวต แล้วสรุปนัด

เว็บ: https://mangob.github.io/wang-mai/

- **แก๊งและนัด** — แก๊ง = กลุ่มเพื่อนที่อยู่ถาวร อยู่ได้หลายแก๊ง ในแก๊งมีได้หลายนัด และเก็บประวัติว่าเคยไปไหนกัน
- **ถามว่าว่างไหม?** — ใครในแก๊งก็เริ่มนัดได้ แล้วได้ข้อความส่งเข้าแชทกลุ่มทันที ชวนคนนอกมาเป็นแขกเฉพาะนัดได้
- **สีประจำตัว** — แต่ละคนมีสติกเกอร์สีของตัวเองบนปฏิทิน เห็นทันทีว่าใครว่างวันไหน
- **ว่างครบแก๊ง** — วันที่ทุกคนว่างและสถานที่ที่ทุกคนโหวตได้กรอบทองพร้อมมงกุฎ
- **สรุปวัน / สรุปสถานที่ แยกกัน** — เลือกจากโหวต ผลสุ่ม หรือเลือกเอง แล้วค่อยปิดนัด
- **สุ่มพร้อมหลักฐาน** — สุ่มวันหรือสถานที่จากตัวเลือกที่ติ๊กไว้ ได้ 3 ครั้งต่อประเภท ทุกครั้งถูกบันทึกและลบไม่ได้
- **ชวนเข้าแก๊ง** — ลิงก์แก๊ง (Google, กดรับคำชวน) หรือลิงก์ส่วนตัว (ไม่ต้องสมัคร) ผู้สร้าง/ผู้ดูแลแก๊งนำออก บล็อก และเปลี่ยนลิงก์ได้

## เทคโนโลยี

- Vue 3 แบบไม่ต้อง build (ES modules + import map)
- Firebase: Firestore, Auth (Google, Anonymous), App Check (reCAPTCHA Enterprise)
- Security rules ตรวจสิทธิ์ตามบทบาทและรูปแบบข้อมูลทุก field
- ทดสอบ rules และ end-to-end บน Firebase Emulator ทุกครั้งที่ push (GitHub Actions + Playwright)
- GitHub Pages
