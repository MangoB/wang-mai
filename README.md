# ว่างไหม (wang-mai)

เว็บนัดเจอเพื่อน: ลงวันว่างบนปฏิทิน เสนอสถานที่ แล้วโหวตวันกับที่นัด

**เว็บ:** https://mangob.github.io/wang-mai/

## ฟีเจอร์

- **เข้าด้วยชื่อ** — ชื่อที่ลงข้อมูลแล้วเลือกกลับมาใช้ต่อได้ ชื่อใหม่ห้ามซ้ำ
- **ปฏิทินวันว่าง** — แตะเพื่อลงหรือเอาออก สีเข้มขึ้นตามจำนวนคนที่ว่าง
- **ลงทีละหลายวัน** — เลือกวันในสัปดาห์และช่วงวันที่ เช่น ทุกเสาร์ทั้งเดือน
- **โหวตวัน** — เรียงตามโหวตและจำนวนคนที่ว่าง
- **สถานที่** — ลิงก์ Google Maps พร้อมแผนที่ฝัง โน้ต และโหวต
- **เริ่มนัดรอบใหม่** — ล้างข้อมูลทั้งหมด ต้องยืนยันก่อน

## เทคโนโลยี

- Vue 3 แบบไม่ต้อง build (ES modules + import map)
- Firebase Firestore พร้อม security rules ตรวจรูปแบบข้อมูลทุก field
- GitHub Pages + GitHub Actions — push ขึ้น `main` แล้ว deploy อัตโนมัติ
