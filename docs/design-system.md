## แนวคิด: สติกเกอร์บนปฏิทินกระดาษ

แก๊งเพื่อนที่แปะสติกเกอร์สี่เหลี่ยมสีของตัวเองบนปฏิทินผนัง — **สีเป็นของคน ไม่ใช่ของแอป**
UI ทั้งหมดใช้หมึกน้ำเงินเข้มบนกระดาษเทาเย็น สีสดมีไว้ให้คนเท่านั้น จึงเห็นทันทีว่าใครว่างวันไหน

ส่วนที่ "กล้า" มีจุดเดียว: **ทอง = ครบทุกคน** — วันที่ว่างครบแก๊ง สถานที่ที่ทุกคนโหวต และตั๋วนัดสำเร็จ ได้กรอบทอง มงกุฎ และรอยบากข้าง ระหว่างหาวัน การ์ดสรุปเป็นแถบเรียบ ๆ ไม่ใช่ทอง ป้าย "โหวตแล้ว" ของตัวเองเป็นสีหมึก ไม่ใช่ทอง

## สถานะช่องวัน

| สถานะ | หน้าตา |
|---|---|
| ไม่มีใครว่าง | ช่องเปล่า เส้นขอบ `--line` |
| มีคนว่าง | สติกเกอร์สี่เหลี่ยม 8–10 px สีของแต่ละคน เรียงเป็นตาราง |
| ฉันว่าง | สติกเกอร์ของฉันมีกรอบหมึก + เลขวันตัวหนา |
| ขาดอีก 1 คน | ช่องสีขาว เส้นประหมึก + สติกเกอร์ว่าง (กรอบเปล่า) แทนคนที่ขาด |
| **ว่างครบแก๊ง** | พื้นทองอ่อน กรอบทอง มงกุฎ รอยบากข้าง ยังเห็นสติกเกอร์ทุกคน คนสุดท้ายที่ทำให้ครบเห็นแสงทองวาบหนึ่งครั้ง |
| สรุปแล้ว (วันนัด) | ป้ายหมุดสีหมึก + ชื่อที่นัด |
| ผ่านไปแล้ว | จาง 40% กดไม่ได้ |

## ตัวอักษร

- **Bai Jamjuree** (600/700) — หัวข้อ, ตัวเลขวันที่, ชื่อห้อง (ทรงเหลี่ยมเข้ากับสติกเกอร์)
- **Anuphan** (400/500/600) — เนื้อหา, ปุ่ม, ฟอร์ม
- สเกล: 13 / 15 / 17 / 22 / 28 / 36 px · body 15/1.6

## รูปทรง

- สติกเกอร์: มุม 2–3 px (สี่เหลี่ยมแท้ ไม่ใช่วงกลม)
- ช่องวัน: มุม 8 px
- แผ่น/sheet: มุม 18 px
- ปุ่ม: สูง ≥ 44 px, มุม 12 px
- ไม่มีเงาทั่วไป — มีเงาเฉพาะ sheet ที่ลอยขึ้นมา

## เสียง (copy)

ภาษาเพื่อนคุยกัน สั้น กริยาตรง: "ฉันว่าง", "สุ่มเลย", "สรุปนัด", "เชิญเพื่อน"
ปุ่มกับผลลัพธ์ใช้คำเดียวกัน: กด "สรุปนัด" → ขึ้น "สรุปนัดแล้ว"

## ลำดับความเด่นในหน้านัด

ชื่อนัด → แถบสรุป (บรรทัดเดียว 📅 วัน | 📍 สถานที่) → **แถบแท็บสีหมึก** (ไอคอน + ตัวเลขสด, ติดบนสุดตอนเลื่อน) → เนื้อหาในการ์ดขาว
ทองโผล่เฉพาะตอนครบทุกคน ปิดนัดแล้วแถบสรุปกลายเป็นตั๋วทอง และซ่อนแถบ "ว่างครบแก๊ง"

## เมนู

เมนูทั้งแอป (โปรไฟล์, หน้าแรก, แก๊งของฉัน, สร้างแก๊งใหม่, ออกจากระบบ): มือถือเปิดจาก ☰ เป็น drawer, จอกว้าง ≥ 900px เป็น sidebar ที่ย่อเหลือไอคอนได้ (จำค่าไว้ในเครื่อง)
