# คำที่ใช้ในเว็บ

ใช้คำตามตารางนี้ทุกที่ (UI, ข้อความส่งเพื่อน, docs) ถ้าจะเปลี่ยนคำ ให้แก้ที่นี่ก่อน

| ใช้ | ไม่ใช้ | ในโค้ด |
|---|---|---|
| แก๊ง | ห้อง | `rooms` |
| นัด | meetup, ทริป | `meetups` |
| ผู้สร้างแก๊ง | เจ้าของ, owner | `role: 'owner'` |
| ผู้ดูแลแก๊ง | co-host | `role: 'cohost'` |
| สมาชิกแก๊ง / สมาชิก | participant | `role: 'participant'` |
| ผู้สร้างนัด | เจ้าของนัด | `meetups.createdBy` |
| แขก | guest (ในข้อความ) | `members.meetId` |
| ลิงก์แก๊ง | ลิงก์ห้อง | `#g-<รหัสแก๊ง>` |
| รหัสแก๊ง | รหัสห้อง | `joinCode` |
| ลิงก์ส่วนตัว | ลิงก์เชิญ, invite | `invites`, `#j-…` |
| วันว่าง | วันที่ว่าง | `avail.dates` |
| สถานที่ | ที่นัด, ร้าน, จุดนัด | `places` |
| โหวต | — | `voteDates`, `votePlaces` |
| ถามว่าว่างไหม? | สร้างนัด | ปุ่มเริ่มนัดใหม่ |
| ชวนเพิ่ม | แชร์ | เปิดหน้า "ส่งให้เพื่อน" ของนัด |
| ชวนเข้าแก๊ง | เชิญเพื่อน | |
| จัดการแก๊ง | ตั้งค่า, สมาชิก (เป็นชื่อหน้า) | |
| สรุปวัน / สรุปสถานที่ | ปักวัน | `meetups.result` |
| ปิดนัด / เปิดนัดอีกครั้ง | สรุปนัด (เป็นปุ่มปิด) | `status: 'done'` |
| ว่างครบแก๊ง | ตั๋วทอง | กรอบทอง |
| ซ่อนในนัดนี้ · นำออก · บล็อก | เตะ | |
