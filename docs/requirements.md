# Requirements — ว่างไหม

สถานะการทำ: `roadmap.md` · คำที่ใช้ในเว็บ: `glossary.md` · security: `security.md`

## แนวคิดหลัก

- **แก๊ง** = กลุ่มเพื่อนที่อยู่ถาวร คนหนึ่งอยู่ได้หลายแก๊ง (ในโค้ดและฐานข้อมูลยังเรียก `rooms`)
- **นัด** = แต่ละครั้งที่นัดกันในแก๊ง มีปฏิทิน โหวต สถานที่ และการสุ่มของตัวเอง
- เริ่มนัดด้วยปุ่ม **"ถามว่าว่างไหม?"**: สร้างนัดแล้วได้ข้อความส่งให้เพื่อนทันที
- จบนัดด้วย **สรุปวัน** และ **สรุปสถานที่** (ทำแยกกันได้) แล้วกด **ปิดนัด** เก็บเป็นประวัติ
- เว็บอยู่ที่ https://mangob.github.io/wang-mai/ ที่เดียว

## บทบาท

| ระดับ | บทบาท | ในโค้ด | เข้าด้วย | ทำได้ |
|---|---|---|---|---|
| ทั้งเว็บ | ผู้ดูแลระบบ | `admins/{uid}` | Google | ดูแลทั้งระบบ |
| แก๊ง | **ผู้สร้างแก๊ง** | `owner` | Google | ทุกอย่างในแก๊ง, ตั้งผู้ดูแลแก๊ง, ลบแก๊ง |
| แก๊ง | **ผู้ดูแลแก๊ง** | `cohost` | Google | ชวนเข้าแก๊ง, จัดการสมาชิก (ยกเว้นตั้งผู้ดูแล), ดูแลทุกนัด |
| แก๊ง | **สมาชิกแก๊ง** | `participant` | Google + ลิงก์แก๊ง หรือ ลิงก์ส่วนตัว | ลงวัน, โหวต, เสนอสถานที่, **สร้างนัด** |
| นัด | **ผู้สร้างนัด** | `meetups.createdBy` | — | ดูแลนัดที่ตัวเองสร้าง (ด้านล่าง) |
| นัด | **แขก** | `members.meetId` | ลิงก์ส่วนตัวของนัด | เห็นและร่วมได้แค่นัดนั้น |

**ดูแลนัด** (ผู้สร้างนัด สำหรับนัดของตัวเอง, ผู้สร้าง/ผู้ดูแลแก๊ง สำหรับทุกนัด):
แก้ชื่อนัด · สรุปวัน · สรุปสถานที่ · ปิด/เปิดนัด · สุ่ม · ชวนแขก · ซ่อนคนในนัดนี้ · ลบนัด
ผู้สร้างนัดจัดการคนในแก๊งไม่ได้ (เตะ บล็อก ตั้งผู้ดูแล) และมอบสิทธิ์ดูแลนัดให้คนอื่นไม่ได้ (ยังไม่ทำ)

## หน้าแรก

1. **ถามว่าว่างไหม?** ปุ่มหลัก เริ่มนัดใหม่
2. **นัดล่าสุด** นัดที่ยังเปิดจากทุกแก๊ง กดเข้านัดได้เลย
3. **แก๊งของฉัน** การ์ดแต่ละแก๊ง กดเข้าหน้าแก๊ง
4. **สร้างแก๊งใหม่** (Google, สูงสุด 5 แก๊งต่อคน)
5. คำชวนเข้าแก๊งที่ยังไม่ได้ตอบ (มาจากลิงก์แก๊ง)

## ชวนเพื่อน

| อยากทำ | ใช้ | ใครทำได้ | ผล |
|---|---|---|---|
| ให้เข้าแก๊ง (มี Google) | **ลิงก์แก๊ง** | ผู้สร้าง/ผู้ดูแลแก๊ง | เพื่อนกดแล้วเห็นหน้า "รับคำชวน" → เป็นสมาชิกแก๊ง |
| ให้เข้าแก๊ง (ไม่ใช้ Google) | **ลิงก์ส่วนตัว** | ผู้สร้าง/ผู้ดูแลแก๊ง | ตั้งชื่อและสีให้ กดครั้งเดียวเข้าได้ |
| ชวนมานัดเดียว | **ลิงก์ส่วนตัวของนัด** (ในหน้า "ส่งให้เพื่อน") | ผู้ดูแลนัด | เป็นแขกของนัดนั้น ถ้าล็อกอินอยู่ ประวัตินัดนั้นติดบัญชีไปด้วย |
| บอกแก๊งว่ามีนัด | ข้อความ **"ว่างไหม?"** + ลิงก์นัด | สมาชิกทุกคน | — |

- ไม่มีการค้นหาหรือชวนคนในแอปที่อยู่แก๊งอื่น (กันคนแปลกหน้า)
- ลิงก์แก๊งเปลี่ยนได้ (ลิงก์เก่าใช้ไม่ได้ คนที่อยู่แล้วอยู่ต่อ)

## จัดการแก๊ง

หน้าเดียว เข้าจากปุ่ม **จัดการแก๊ง** ในหน้าแก๊ง:
- **ชวนเข้าแก๊ง** (ลิงก์แก๊ง, ลิงก์ส่วนตัว)
- **สมาชิก** แยกตามบทบาท แต่ละคนมีเมนู: ตั้ง/ถอดผู้ดูแล · ให้เป็นแขกเฉพาะนัด · นำออก · บล็อก
- **ลิงก์ที่ยังไม่มีคนใช้**
- **สีของฉันในแก๊งนี้**
- **ชื่อแก๊ง** · **ลบแก๊ง** (ผู้สร้างแก๊ง, ยืนยันก่อน)

| คำสั่ง | ผล | ย้อนได้ |
|---|---|---|
| ซ่อนในนัดนี้ | ยังอยู่ในแก๊ง แต่ไม่นับในนัดนั้น | เลิกซ่อน |
| นำออก | ออกจากแก๊ง | ชวนใหม่ได้ |
| บล็อก | ออก และกลับเข้าแก๊งนี้ไม่ได้ | ปลดบล็อก |
| ลบแก๊ง | ทุกอย่างหาย | ไม่ได้ |

## ในนัด

1. การ์ด **สรุปนัด** บนสุด: 📅 วัน · 📍 สถานที่ (ที่ยังไม่สรุปเขียนว่า "ยังไม่ได้เลือก") ผู้ดูแลนัดกดแก้ได้
2. **สรุปวัน** และ **สรุปสถานที่** ทำแยกกัน เลือกจากรายการไหนก็ได้ ไม่จำเป็นต้องเป็นอันที่โหวตมากสุด หรือใช้ผลสุ่ม
3. **ปิดนัด** ปุ่มแยก ปิดแล้วลงวัน/โหวตไม่ได้ เปิดใหม่ได้
4. แท็บ: **วันว่าง · สถานที่ · สุ่ม**
5. **ใครอยู่ในนัดนี้** พับเก็บไว้ กดเปิดได้
6. ปุ่ม **ชวนเพิ่ม** เปิดหน้า "ส่งให้เพื่อน" (ข้อความถามแก๊ง + ใครยังไม่ลง + ชวนแขก)

### การสุ่ม
- สุ่มได้ทั้งวันและสถานที่ จากตัวเลือกที่ติ๊ก (ค่าเริ่มต้น: วันที่ว่างมากสุด / สถานที่ที่โหวตมากสุด)
- สุ่มได้ไม่เกิน 3 ครั้งต่อนัดต่อประเภท บันทึกทุกครั้ง: ใคร เมื่อไร ตัวเลือก ผล (แก้หรือลบไม่ได้)
- ผลสุ่มกด "ใช้สรุปวัน/สรุปสถานที่" ได้ทันที

### สถานที่
- แปะลิงก์ Google Maps + ชื่อ + โน้ต, โหวตได้
- รูปและที่อยู่จาก Google: ภายหลัง (ต้องใช้ Places API ในโปรเจกต์แยกที่ผูกบัตร + เพดานรายวัน)

## ข้อจำกัดของระบบ

- Firebase แพ็กเกจฟรี (Spark) ไม่มี server ของเราเอง
- คนในแก๊งเห็นเฉพาะคนในแก๊งเดียวกัน แขกเห็นแค่นัดของตัวเอง
- ไม่เก็บอีเมลใน Firestore

## ภายหลัง

- เวลานัด (ไม่ใช่แค่วัน)
- มอบสิทธิ์ดูแลนัดให้คนอื่น
- ย้ายประวัติจากลิงก์ส่วนตัวเข้าบัญชี Google
- รูปสถานที่
- โอนความเป็นผู้สร้างแก๊ง, หน้า admin, แจ้งเตือน

ตัดสินแล้ว: รหัสแก๊ง 6 ตัว / รหัสส่วนตัว 8 ตัว (ตัด 0/O, 1/I) · ใช้ "สถานที่" ไม่ใช้ "ที่นัด"
