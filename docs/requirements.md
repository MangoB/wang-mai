# Requirements — ว่างไหม v2

สถานะ: ร่าง · security: `security.md` · ลำดับงาน: `roadmap.md`

## แนวคิดหลัก

- **ห้อง (Room)** = แก๊งเพื่อน อยู่ถาวร สมาชิกอยู่ระดับห้อง
- **นัด (Meetup)** = แต่ละครั้งที่นัดกันในห้อง มีปฏิทิน โหวต สถานที่ และการสุ่มของตัวเอง
- จบนัดด้วย **"สรุปนัด"** (ปักวัน + ที่) แล้วเก็บเป็นประวัติ — แทนปุ่ม reset เดิม

## บทบาท

| ระดับ | บทบาท | วิธีเข้า | ทำได้ |
|---|---|---|---|
| ทั้งเว็บ | **Admin** | Google (บัญชีที่มีธง admin) | ดูแลทั้งระบบ: ลบห้องผิดปกติ, แบนบัญชี, ดูการใช้โควตา |
| ในห้อง | **Owner** | Google | ทุกอย่างของ participant + ดูแลห้อง (ด้านล่าง) |
| ในห้อง | **Co-host** | Google | ช่วย owner ดูแลห้อง + สุ่ม |
| ในห้อง | **Participant** | member: Google + รหัสห้อง · guest: ลิงก์เชิญ / รหัสห้อง + รหัสส่วนตัว | ลงวัน, โหวต, เพิ่มสถานที่,  |

- guest และ member เป็นบทบาทเดียวกันในห้อง ต่างกันแค่วิธีเข้า
- **Guest:** owner สร้างตัวตนให้ (ตั้งชื่อ) ระบบ gen รหัสส่วนตัวต่อห้อง ใช้รหัสบนเครื่องใหม่ได้ (เครื่องเก่าหลุดสิทธิ์)
- **Member:** ตั้งชื่อ profile เอง, ใส่รหัสห้องแล้ว **เข้าได้ทันทีไม่ต้องอนุมัติ**, ห้องที่เคยเข้าจำไว้ในบัญชี
- **Member สร้างห้องได้** (จำกัดจำนวนต่อคน เช่น 5) และเป็น owner

## การดูแลห้อง (owner)

| คำสั่ง | ผล | ย้อนได้ |
|---|---|---|
| ซ่อน | ยังอยู่ในห้อง แต่ไม่นับในผลรวม/โหวตของนัดนี้ | เลิกซ่อน |
| เตะออก | ออกจากห้อง ข้อมูลหายจากนัด | เข้าใหม่ได้ถ้ามีรหัส |
| บล็อก | ออก และห้ามกลับเข้าห้องนี้ | ปลดบล็อก |
| เปลี่ยนรหัสห้อง | รหัสเก่าใช้เข้าไม่ได้ คนที่อยู่แล้วอยู่ต่อ | — |
| ลบห้อง | ทุกอย่างหาย (modal ยืนยัน) | ไม่ได้ |

## ฟีเจอร์ในนัด

1. **ปฏิทินวันว่าง** + ลงทีละหลายวัน (เหมือน v1)
2. **โหวตวัน** (เหมือน v1)
3. **สถานที่** — แสดง **รูปสถานที่** + **ที่อยู่/ย่าน** + แผนที่ + โหวต (ดู "สถานที่" ด้านล่าง)
4. **สุ่ม** (ดู "การสุ่ม" ด้านล่าง)
5. **สรุปนัด** — เลือกวัน + ที่สุดท้าย (จากโหวตหรือผลสุ่ม) แสดงบนสุด, เก็บในประวัติห้อง

### การสุ่ม

- สุ่มได้ทั้ง **วัน** และ **สถานที่**
- เลือกเองว่าจะสุ่มจากตัวเลือกไหนบ้าง (ติ๊กจากลิสต์ ไม่ใช่ทุกอัน) — ค่าเริ่มต้นติ๊กให้: วันที่ว่างมากที่สุด / ที่ที่โหวตมากที่สุด
- **หลักฐาน:** ทุกครั้งที่สุ่มบันทึก ใครสุ่ม, เมื่อไร, ตัวเลือกที่เข้าร่วมทั้งหมด, ผลที่ได้
- **สุ่มได้ไม่เกิน 3 ครั้งต่อนัด ต่อประเภท** (วัน 3 / สถานที่ 3) — เกินนั้นให้เลือกเอง; ผลเก่ายังอยู่ในประวัติ (แก้หรือลบไม่ได้ — บังคับใน rules)
- ผลสุ่มกด "ใช้ผลนี้สรุปนัด" ได้ทันที ไม่ต้องรอโหวตครบ

### สถานที่

- เพิ่มสถานที่ได้ 2 ทาง: **ค้นหาชื่อร้าน** (autocomplete) หรือแปะลิงก์ Google Maps
- การ์ดสถานที่: รูปจริงของสถานที่, ชื่อ, ที่อยู่/ย่าน, ปุ่มเปิด Google Maps, โน้ต, โหวต
- ข้อจำกัด: รูปและที่อยู่จาก Google ต้องใช้ Places API ซึ่ง **ต้องผูกบัตร** กับ Google Cloud (มีโควตาฟรีรายเดือน) — ต้องตัดสินใจ ดู "คำถามที่ยังเปิด"

## ข้อจำกัดของระบบ

- ใช้ Firebase แพ็กเกจฟรี (Spark) ต่อไป ไม่มี server ของเราเอง
- จำกัดจำนวนห้องต่อ member กันโควตาหมด
- คนในห้องเห็นเฉพาะคนในห้องเดียวกัน
- มองไม่เห็น IP ของผู้ใช้ (ไม่มี server) — กันคนแปลกหน้าด้วยรหัสห้อง + บล็อกราย uid + เปลี่ยนรหัสห้องแทน

## รอบการพัฒนา

**MVP**
- ล็อกอิน Google + guest (ลิงก์/รหัส)
- สร้างห้อง (member), owner, ดูแลห้องครบตามตาราง
- หลายนัดต่อห้อง, สรุปนัด, ประวัติ
- ปฏิทิน, โหวตวัน, สถานที่, **สุ่มพร้อมหลักฐาน**
- จำห้องที่เคยเข้า
- ย้ายนัดแรก (v1) เข้าห้องแรกหลังนัดจบ: ทุกคนเป็น guest + ประวัตินัดแรก
- guest อัปเกรดเป็น member ด้วยรหัสของตัวเอง ประวัติตามไปด้วย (ดู `roadmap.md`)

**ภายหลัง**
- ตั้ง **เวลา** นัด (ไม่ใช่แค่วัน)
- โอนความเป็นเจ้าของห้อง
- หน้า admin ภาพรวมทั้งระบบ
- แจ้งเตือน (เช่น LINE เมื่อสรุปนัด)
