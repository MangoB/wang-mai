# Roadmap

ขอบเขต: `requirements.md` · security: `security.md` · หน้าตา: `design-system.md`

แบบหน้าตา: canvas "ว่างไหม v2" (แถวบนสุดคือรอบล่าสุด)

## Phase 1 — ระหว่างนัดแรก

- [x] Firebase Emulator สำหรับพัฒนาในเครื่อง
- [x] ทดสอบ security rules บน emulator ทุกครั้งที่ push (`npm test`)
- [x] ทดสอบผ่านเบราว์เซอร์จริงแบบ end-to-end (`npm run test:e2e`)
- [x] App Check (reCAPTCHA Enterprise) ใน v1 และ v2
- [ ] Enforce App Check หลังดูกราฟ verified requests
- [x] v2 รุ่นทดลองที่ `/v2/`: ห้อง, guest, member Google, หลายนัด, ว่างครบแก๊ง, สถานที่, สุ่มพร้อมหลักฐาน, สรุปนัด, ดูแลสมาชิก
- [x] ทดลองใช้ v2 กับกลุ่มเล็ก (แก๊งเรา)

## Phase 2 — ย้ายนัดแรกเข้า v2 (เลื่อนมาทำระหว่างนัด ตาม `docs/decisions/0001`)

- [x] ห้อง "แก๊งเรา" + ลิงก์เชิญ 7 คน (ชื่อตรงกับ v1) ส่งลงกลุ่มแล้ว
- [x] ปุ่ม "ดึงข้อมูลจากลิงก์เดิม" สำหรับ admin ที่เป็นเจ้าของห้อง (ทำในเบราว์เซอร์ผ่าน rules ไม่ใช้ service account key) กดซ้ำได้
- [x] แขกเฉพาะนัด (`meetId`)
- [x] เผยแพร่ rules → ดึงข้อมูล → ตั้ง ณัฐ นอต แพร เป็นแขกของ "นัดแรก"
- [x] Cutover: แจ้งแก๊ง → ดึงข้อมูลรอบสุดท้าย → merge `feature/v1-cutover` → เผยแพร่ rules (ปิดการเขียน v1)
- [x] เอาปุ่มและสิทธิ์ดึงข้อมูลออก
- [ ] หลังนัดจบและตรวจว่าครบ: ลบ `people`/`places` ของ v1

## Phase 2.5 — แก๊ง การชวน และสรุปนัด

ตกลงกันแล้วใน `requirements.md` · คำที่ใช้: `glossary.md`

- [x] requirements + glossary + แบบใน canvas
- [x] ย้ายแอปจาก `/v2/` มาที่ root (ไม่ทำ redirect)
- [x] ห้อง → แก๊ง ทั้งเว็บ, ตรวจคำตาม glossary
- [x] หน้าแรก: ถามว่าว่างไหม?, คำชวนที่รอตอบ, นัดล่าสุด, แก๊งของฉัน, สร้างแก๊งใหม่
- [x] ถามว่าว่างไหม? → ตั้งนัด → ส่งให้เพื่อน (ข้อความ + ใครยังไม่ลง + ชวนแขก) และปุ่ม "ชวนเพิ่ม" ในนัด
- [x] สมาชิกทุกคนสร้างนัดได้ ผู้สร้างนัดดูแลนัดของตัวเอง (rules + เทส)
- [x] ลิงก์แก๊ง `#g-<รหัส>` + หน้ารับคำชวน
- [x] หน้าจัดการแก๊ง (ชวน, สมาชิก, ลิงก์ที่ยังไม่ใช้, สีของฉัน, ชื่อแก๊ง, ลบแก๊ง)
- [x] ในนัด: การ์ดสรุปนัดบนสุด, สรุปวัน/สรุปสถานที่แยกกัน, ปุ่มปิดนัดแยก, "ใครอยู่ในนัดนี้" พับได้, "ไม่ไปรอบนี้"
- [x] คนเดียวกันที่เปิดลิงก์ส่วนตัวหลายเครื่องนับเป็นคนเดียว และตั้งแขกเฉพาะนัดได้ทุกเครื่อง
- [x] ข้อความส่งเพื่อนชุดใหม่ (ลิงก์ไม่มี /v2)

## Phase 2.6 — เมนูและความเด่นในหน้านัด

- [x] เมนูทั้งแอป: drawer บนมือถือ, sidebar ย่อได้บนจอกว้าง
- [x] แถบแท็บสีหมึกพร้อมตัวเลข, แถบสรุปบรรทัดเดียว, ตั๋วทองเมื่อนัดสำเร็จ
- [x] ลงทีละหลายวันที่หัวปฏิทิน, ป้าย "โหวตแล้ว" สีหมึก + "ยกเลิกโหวต"
- [x] เจ้าตัวกด "ไม่ไปรอบนี้" / "ไปด้วย" เองได้

## Phase 3 — รวมประวัติเข้าบัญชี

- [x] เข้าด้วยลิงก์ส่วนตัวแล้วล็อกอิน Google: ผูกตัวตนเดิมเข้าบัญชี (uid เดิม) กลายเป็นสมาชิกแก๊งในชื่อโปรไฟล์ ประวัติ วันว่าง และโหวตตามมาครบ
- [x] ล็อกอิน Google ก่อนแล้วกดลิงก์ส่วนตัว: ได้ผลเหมือนกัน
- [x] บัญชี Google ที่เคยใช้ในเครื่องอื่นแล้ว: ล็อกอินแล้วรับลิงก์ส่วนตัวที่เครื่องนี้เคยกดมาด้วย
- [ ] ถ้าทำลิงก์หาย ผู้สร้าง/ผู้ดูแลแก๊งสร้างลิงก์ใหม่ให้คนเดิม (pid เดิม) ได้

## Phase 4 — รูปสถานที่

โปรเจกต์ Google Cloud แยก + เพดานรายวัน (ดู `security.md`) → ค้นชื่อร้าน รูปจริง และที่อยู่

## ภายหลัง (สนใจทำ ยังไม่ได้ตกลงรอบ)

- เลือกธีมเองได้ (สว่าง / มืด / ตามเครื่อง) ตอนนี้ตามการตั้งค่าของเครื่องอย่างเดียว
- ตั้งเวลานัด (ไม่ใช่แค่วัน)
- มอบสิทธิ์ดูแลนัดให้คนอื่น (ผู้ช่วยดูแลนัด)
- โอนความเป็นผู้สร้างแก๊ง
- หน้า admin ภาพรวมทั้งระบบ
- แจ้งเตือนผ่าน LINE เมื่อสรุปนัดหรือมีนัดใหม่
- ลบข้อมูล v1 (`people`/`places`) หลังนัดแรกจบและตรวจว่าครบ
- Enforce App Check (ค้างจาก Phase 1)
