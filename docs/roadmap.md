# Roadmap

ขอบเขต: `requirements.md` · security: `security.md` · หน้าตา: `design-system.md`

แบบหน้าตา: canvas "ว่างไหม"

ทั้งหมด 5 phase: 1–2 เสร็จแล้ว, 3–5 คือที่เหลือ

## Phase 1 — ความปลอดภัยและเครื่องมือ ✓

- [x] Firebase Emulator สำหรับพัฒนาในเครื่อง
- [x] ทดสอบ security rules บน emulator ทุกครั้งที่ push (`npm test`)
- [x] ทดสอบผ่านเบราว์เซอร์จริงแบบ end-to-end (`npm run test:e2e`)
- [x] จำกัด API key เฉพาะโดเมนจริง, App Check (reCAPTCHA Enterprise) ลงทะเบียนและส่ง token แล้ว

## Phase 2 — แก๊งและนัด (เวอร์ชันปัจจุบัน) ✓

ย้ายนัดแรกเข้ามา: `docs/decisions/0001` · ขอบเขต: `requirements.md` · คำที่ใช้: `glossary.md`

- [x] แก๊ง (หลายแก๊ง), นัดหลายนัด, ลิงก์แก๊ง + หน้ารับคำชวน, ลิงก์ส่วนตัว, แขกเฉพาะนัด
- [x] บทบาท: ผู้สร้างแก๊ง / ผู้ดูแลแก๊ง / สมาชิกแก๊ง / ผู้สร้างนัด, จัดการแก๊ง (นำออก บล็อก เปลี่ยนลิงก์)
- [x] ถามว่าว่างไหม? (ใครก็เริ่มนัดได้) + ส่งให้เพื่อน
- [x] สีประจำตัว, ว่างครบแก๊ง, ลงทีละหลายวัน, โหวต, สถานที่, สุ่มพร้อมหลักฐาน
- [x] สรุปวัน / สรุปสถานที่แยกกัน, ปิดนัด (ตั๋วทอง), ไม่ไปรอบนี้ / ไปด้วย
- [x] เมนูทั้งแอป: drawer บนมือถือ, sidebar ย่อได้บนจอกว้าง
- [x] ย้ายนัดแรกจาก v1 เข้ามา, ปิดการเขียน v1, แอปอยู่ที่ลิงก์หลัก
- [x] เข้าด้วยลิงก์แล้วล็อกอิน Google (ก่อนหรือหลังก็ได้) → เป็นสมาชิกในชื่อโปรไฟล์ ประวัติตามไปด้วย

## Phase 3 — ใช้จริงให้ลื่น (ถัดไป)

งานเล็ก ไม่มีค่าใช้จ่าย ทำได้ในแพ็กเกจฟรี

- [ ] Enforce App Check (ดูกราฟ verified requests ใน console ก่อน แล้วกดเปิด) — รอให้เพื่อนใช้กันเยอะก่อน มีตัวเตือน 14 พ.ย.
- [ ] ลองด้วยมือ: เปิดลิงก์ส่วนตัวใน incognito → ล็อกอิน Google ด้วยบัญชีสำรอง → ชื่อและวันว่างต้องอยู่ครบ (ขั้นหน้าต่างล็อกอินเทสอัตโนมัติไม่ได้)
- [ ] ลบ branch เก่าบน GitHub ที่ค้างอยู่ (เหลือแค่ `main`)
- [ ] ทำลิงก์ส่วนตัวหาย: ผู้สร้าง/ผู้ดูแลแก๊งออกลิงก์ใหม่ให้คนเดิม (pid เดิม ข้อมูลเดิมอยู่ครบ)
- [ ] เลือกธีมเอง: สว่าง / มืด / ตามเครื่อง (ตอนนี้ตามเครื่องอย่างเดียว)
- [ ] ตั้งเวลานัด (ไม่ใช่แค่วัน) ในการ์ดสรุปและตั๋วนัด
- [ ] หลังนัดแรกจบและตรวจว่าครบ: ลบ `people`/`places` ของ v1 และ rules ส่วน v1

## Phase 4 — ดูแลแก๊งและนัด

- [ ] มอบสิทธิ์ดูแลนัดให้คนอื่น (ผู้ช่วยดูแลนัด)
- [ ] โอนความเป็นผู้สร้างแก๊ง
- [ ] หน้าผู้ดูแลระบบ (admin): ภาพรวมแก๊งทั้งหมด จำนวนการใช้งาน ใกล้เพดานแพ็กเกจฟรีหรือยัง

## Phase 5 — สถานที่จริงและแจ้งเตือน (ต้องคุยเรื่องค่าใช้จ่ายก่อน)

- [ ] รูปสถานที่และที่อยู่: ค้นชื่อร้านแล้วได้รูปจริง ใช้ Places API ในโปรเจกต์ Google Cloud แยกที่ผูกบัตร + เพดานรายวัน (ดู `security.md`)
- [ ] แจ้งเตือนผ่าน LINE เมื่อมีนัดใหม่หรือสรุปนัดแล้ว: ต้องมีส่วนที่รันบน server (เช่น Cloud Functions ซึ่งต้องใช้แพ็กเกจ Blaze) และ LINE Official Account
