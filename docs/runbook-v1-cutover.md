# Runbook: ย้ายนัดแรกจาก v1 เข้า v2

ที่มา: `docs/decisions/0001-first-meetup-into-v2.md`
ห้อง: "แก๊งเรา" (เจ้าของ: หยก, รหัสห้อง U94-SFF)

## A. เปิดใช้นัดแรกใน v2 (ลิงก์เดิมยังใช้ได้)
1. เผยแพร่ `firestore.rules` จาก `main` (Firebase console → Firestore → Rules → วางไฟล์ → Publish หรือ `firebase deploy --only firestore:rules`)
2. เข้า https://mangob.github.io/wang-mai/v2/ ด้วยบัญชี admin → ห้อง "แก๊งเรา" → การ์ด "นัดแรกจากลิงก์เดิม" → **ดึงข้อมูลจากลิงก์เดิม**
   ข้อความผลต้องไม่มี "ไม่พบชื่อในห้อง" ถ้ามี แปลว่าชื่อใน v1 ไม่ตรงกับลิงก์เชิญ
3. หน้าสมาชิก → ณัฐ, นอต, แพร → "อยู่ใน: แขกเฉพาะ นัดแรก"
   ถ้ายังไม่กดลิงก์ ให้ตั้งที่รายการ "ลิงก์เชิญที่ยังไม่มีคนใช้" แทน
4. ระหว่างนี้ใครลงข้อมูลในลิงก์เดิม ให้กด "ดึงข้อมูลล่าสุดอีกครั้ง" ได้ ข้อมูลของคนที่แก้ใน v2 แล้วจะไม่ถูกทับ

## B. Cutover (เลิกใช้ลิงก์เดิม)
1. แจ้งในกลุ่มว่าจะย้ายแล้ว และให้ทุกคนใช้ลิงก์ชื่อตัวเอง
2. กด "ดึงข้อมูลล่าสุดอีกครั้ง" รอบสุดท้าย
3. merge `feature/v1-cutover` เข้า `main` ลิงก์เดิมจะกลายเป็นหน้าชี้ไป v2
4. เผยแพร่ rules จาก `main` เพื่อปิดการเขียน `people`/`places`

ย้อนกลับ: revert commit ของข้อ 3 แล้วเผยแพร่ rules เดิมอีกครั้ง ข้อมูล v1 ยังอยู่ครบ
